## 本版亮点

**这一版加上了应用内更新。** 偏好新增「关于」组，显示本机正在运行的版本号，并对照 GitHub 仓库
`fraternidaddeng/clipsync` 的最新正式 Release（`/releases/latest`，不含预发布）决定要不要升。
检查不会偷偷下载；发现新版本后由你点「下载并安装」。文件落地后先核 SHA-256（优先用 Release
资产的 `digest`，没有再拉 `.sha256` 侧车），对不上就丢掉、不安装。

Android 把已校验 APK 交给系统安装器（需允许本应用安装未知来源）；Windows 便携目录在应用退出后
由助手脚本覆盖再重启——用户数据在 LocalAppData，不会被碰到。

**谁该升级：还在用 `v0.2.0` 或更早版本、希望以后不用每次去网页下包的人。** 本版是这条通路的
起点：`v0.2.0` 里没有检查器，**升到 0.3.0 必须从本页手动下载一次**；装上之后，再出的正式
发布就可以在应用里完成。

## 升级说明

- **Android**：与 `v0.2.0` 同签名密钥时可直接覆盖安装（versionCode `20099` → `30099`），
  **配对与历史不丢**。debug 签名包与正式包互不兼容——换签名必须先卸载，卸载会删除设备上的
  历史与配对。
- **Windows**：解压覆盖即可，`%LOCALAPPDATA%\ClipSync` 数据目录不受影响。回滚 = 换回旧的
  解压目录。本版起，之后的正式发布可在偏好 · 关于里下载并替换该便携目录。
- **无需重新配对**：本版未改配对协议、密钥格式与协议版本协商。
- 全新安装、配对、授权与排障见 `docs/install.md`（Windows 便携 ZIP 内亦附带）。安装前请核对
  Release 正文注明的 SHA-256（与产物旁 `.sha256` 文件一致）。
