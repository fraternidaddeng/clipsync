# ClipSync v0.5.1

- 发布日期：2026-10-09
- 分支/标签：`v0.5.1`（自 `main`）

## 本版亮点

检查更新只告诉你有没有新版本。无线调试按当前这一步来：先扫码或填配对码，连过一次或连不上时才填连接地址。

## 升级说明

- **Windows**：应用内更新会替换便携目录后重启。`%LOCALAPPDATA%\ClipSync` 里的配对与历史不动。
- **Android**：已安装官方正式签名的 v0.5.0 时，覆盖安装保留配对与历史。
