# ClipSync v0.5.0

- 发布日期：2026-10-09
- 分支/标签：`v0.5.0`（自 `main`）

## 本版亮点

### 1. 国内网络可以检查并下载更新
检查和下载仍先访问 GitHub 正式地址。连不上时再按顺序试 `ghproxy.net`、`ghfast.top`、`mirror.ghproxy.com`。安装前的 SHA-256 校验不变。镜像只能看到发起更新请求的 IP，看不到剪贴板内容。

### 2. 无线调试换端口不用重新配对
连接被拒绝时不再把系统错误读成一串乱码。成功连接过的地址会记住；旧端口不再监听时，用手机当前广播的无线调试端口再连一次，并写明配对还在。启动时只回填地址，不会自己去连。

### 3. 引导按实际能力来写
配对完成只表示配对完成。后台读取和自动写入需要另外确认。安装指南顶部按任务列出入口。

### 4. Android 触压与底栏动效
按下有统一的微压反馈，并跟随系统减弱动效。底栏当前页有跳跃和指示器展开，通路页折叠箭头平滑翻转。

## 验证状态（诚实声明）

- **自动化**：定版提交没有重跑全量套件。无线连接相关单测在定版前本地通过（编码 6 项、无线视图模型 12 项）。动效提交 `0233f1b` 的说明称当时 Android 单测、ktlint 与 detekt 已通过。打包与产物校验以 tag 触发的 `release.yml` 为准；发布不等于真机验证通过。
- **人工 QA**：本版没有新跑一遍 `docs/manual-qa-checklist.md`。无线端口这条来自 2026-10-09 的真机失败现象（连接被拒绝、界面乱码）。

## 已知限制

- 手机上已安装的 v0.4.0 没有镜像和无线端口这两项，要等本版装上之后才有。
- 测试包与正式包签名不同，覆盖安装仍须先卸载，卸载会清掉手机上的配对与历史。同一正式签名的后续更新保留配对。
- Windows 引导文案本版改了简体、繁体、英文、日文；其余语言键完整，句子可能还是旧说法。

## 升级说明

- **Windows**：解压覆盖即可。`%LOCALAPPDATA%\ClipSync` 里的配对与历史不动。
- **Android**：已安装官方正式签名的 v0.4.0 时，用本版已签名 APK 覆盖安装，配对与历史保留。不要用调试包覆盖。
