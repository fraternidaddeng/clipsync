# ClipSync v0.5.6

- 发布日期：2026-10-09
- 分支/标签：`v0.5.6`（自 `main`）

## 本版亮点

Windows 桌面端补齐与手机端一致的软弹微交互与转场动效：左栏导航加入滑动药丸指示器与图标回弹，历史列表增删条目改为无高度挤压的纯位移平滑让位，所有按钮、筛选胶囊、步进器、通路段卡片、设备色圆点与托盘浮窗卡片统一接入按压缩放回弹与页面上浮切入。

## 升级说明

- **Windows**：应用内更新替换便携目录后重启。配对与历史留在 `%LOCALAPPDATA%\ClipSync`。
- **Android**：这一版没有手机界面改动。覆盖安装官方正式签名包会保留配对与历史。
