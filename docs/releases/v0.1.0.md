## 本版亮点

首个版本。ClipSync 是一个只做 Windows ↔ Android、无账号无云无中转的私有直连剪贴板同步工具：
复制即落库，在线即近实时互通，断线后按序号补齐不重不漏（exactly-once，协议级保证）。配对像蓝牙
一样一次完成——扫码、比对指纹、双向确认；内容只在你的两台设备之间走 TLS 1.3 + 证书指纹固定的
直连通道，第三方进程永远碰不到。

Android 10+ 的后台剪贴板读取是系统刻意限制的能力。本版把它拆成四档能力阶梯诚实交付：特权直读
（内置特权宿主事件通道）、ADB 日志 + 悬浮窗（四族 ROM 版本化解析器）、悬浮窗轮询（无电脑兜底）、前台/
手动。每一档的「读」与「写回」分开探测、分开显示，通路页只说真话——探到授权不等于 READY。
**注意：三档后台读取的真机验证已于 2026-08-26 经用户签核完成，逐设备明细待回填（见「已知限制」）。**

其余能力一览：双端历史/搜索/删除/导出导入、暂停/私密/来源黑名单策略逐层真实执行、图片同步
（protocol v2，默认双端关闭、显式开启）、蓝牙备援（IP 全不可达时 RFCOMM 续传文本，默认关）、
19 种界面语言、日/夜主题与设计宪章 UI、开机自启（Windows）/开机恢复（Android，默认关）。

## 变更明细

首个版本：以下按平台归并主要能力；逐条流水见 `CHANGELOG.md` 的 v0.1.0（原 Unreleased）节。

### 新增

- [双端] 协议 v1 全消息集（challenge/auth、known_vector/want_ranges、announce/fetch/payload、
  ack_ranges、重放窗口）；断线补齐 exactly-once，由真实 TLS + WebSocket 回环集成测试证明。
- [双端] 图片同步（protocol v2 分块传输、缩略图历史/详情；默认双端关闭，fail-closed）。
- [双端] 历史导出/导入（v1 文本、v2 图片感知格式）；删除以 tombstone 传播不带正文。
- [双端] 蓝牙备援传输（ADR 0005，默认关；bt1 安全信道：HMAC 双向认证 + AES-256-GCM）。
- [双端] 暂停/私密模式在捕获、队列、引擎逐层真实关断，恢复后补投无丢失。
- [双端] 设计宪章 UI：令牌系统、日/夜主题（含手动覆盖）、随包三字族、19 语界面（源语言中文）。
- [Windows] 后台捕获、SQLite 历史、Kestrel 直连监听端、QR 配对、UDP 发现、托盘四态图标 +
  浮窗、自绘标题栏、全局呼出快捷键、开机自启（默认关）。
- [Android] Room 同步栈、前台服务、三个无权限入口（分享面板/快捷磁贴/通知复制）、前台自动捕获、
  收件箱 + 自动写回、四档后台读取能力阶梯与通路页真实探针、开机恢复链（默认关）。

### 变更

- 无（首个版本）。

### 修复

- 无（首个版本；开发期缺陷修复不在用户可见变更之列，见 `CHANGELOG.md`）。

### 安全

- 传输：TLS 1.3 + 证书指纹固定（pin 不符绝不降级）、每对设备独立 secret、trust epoch 撤销即断连。
- 抗滥用：认证节流 + 锁定通知、预认证 per-IP 滑窗限流、会话内帧级限流（RATE_LIMITED 可重试）、
  超大帧/超限拉取稳定错误码。
- 日志卫生：剪贴正文、密钥、nonce 永不入日志/通知（有专门测试钉死）。
- Android：备份/设备迁移全域排除（剪贴历史是敏感明文）；系统代理（Clash/Surge 等）下双端显式直连。
- 蓝牙备援：bt1 安全信道（共享 secret HMAC 双向认证、HKDF 按方向派生 AES-256-GCM、防重放/乱序/
  截断，负例测试覆盖）；图片不过蓝牙。
