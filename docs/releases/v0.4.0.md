# ClipSync v0.4.0

- 发布日期：2026-09-16
- 分支/标签：`v0.4.0`（自 `main`）

## 本版亮点

### 1. 动效与微交互体验全面升级（丝绸重力垂坠与空间连续性）
- **彻底杜绝列表积压反模式**：彻底解决并摒弃了剪贴项入舱与移除时 `height: 0` 压缩挤出的别扭手感，改用稳定的视口物理高度与 FLIP 空间连续性位移让位（`Modifier.animateItem`）。
- **动效预览与参数调校实验室**：随包交付 [`docs/design/animation_preview.html`](../design/animation_preview.html)，提供 12 组物理动效实机推演，内置 A/B 质感切换（软羽入舱 vs 生硬挤出，槽位腾挪 vs 原地压缩），支持 1.0x / 0.4x（慢放观摩微挤压）/ 1.5x 速率与 GSAP 物理阻尼参数实时调校。
- **Windows 核心交互质感革新**：
  - `CharterToggle` 开关：摒弃硬切，引入莱卡相机凸轮过中点阻尼机制（`TranslateTransform.X: 0 → 20`、第 70ms 预冲微压 `Scale 1.12 / 0.94`、`SplineDoubleKeyFrame 0.16,1 0.3,1` 双层轨道渐变）。
  - `FoldToggle`：Chevron 箭头引入 220ms `CubicEase` 平滑回旋故事板（0° ↔ 90°）。
  - `TrayFlyoutWindow`：托盘小窗实现 8px 气压升降进出舱与卡片触觉微压反馈（`Scale 0.992`）。
  - `PairingApprovalWindow`：补齐审批成功后的 18° 倾斜镜面流光扫过礼赞仪式。
- **Android Compose 交互平滑度优化**：
  - `HomeScreen`：分类筛选药丸引入 `animateColorAsState` 与 `CharterMotion.spec`，选中状态温润平滑。
  - `PreferencesScreen`：语言与分段选择药丸引入平滑色彩与边框缓动过渡。

### 2. Windows 防火墙自动检测与一键放行 / 移除 (ADR 0006)
- 根治真机测试中「手机扫码后电脑毫无反应」的核心病灶（TCP 47654 被 Windows 防火墙拦截）。
- COM 晚绑定只读检测，提供「已放行 / 未发现放行规则 / 无法判断」三态，并在放行时自动清理历史生成的阻止规则。

### 3. 配对局域网信标与不可达原因分层诊断
- 二维码窗口出示期间启用 2 秒快速 UDP 广播信标，多网卡地址按物理网卡梯队自动排序。
- 手机端按 errno 分层指出超时、拒绝、同网段未放行等明确病灶，彻底告别「等待 90 秒超时却不知为何」。

### 4. 非 UI 层性能第二轮审计优化
- 图片分片编解码零拷贝化（`System.Buffers.Text.Base64` + `SearchValues` + `ArrayPool`），接收吞吐大幅跃升。
- PNG 编码器去掉大负载 stackalloc 避免栈溢出风险，大图落盘与缩略图复用流式哈希。

### 5. 特权直读与无线调试稳定性修复
- Windows 识别 adb 37 的 mDNS 设备序列号，根除连接成功后误报离线的问题。
- 修复 Android 特权直读在 UserService 异步冷启动时验证读抢跑的死循环。
