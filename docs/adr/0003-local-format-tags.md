# ADR 0003：本地内容形态标签（检索辅助，非 ML）

- 状态：接受
- 日期：2026-08-24

## 背景

历史一长，人找内容靠的往往不是关键词，而是「那是个链接」「那条是验证码」这样的形态印象。两端历史页只有文本搜索，缺一条按形态收窄的路。

候选做法有三种：云端/模型分类、本地 ML、本地启发式规则。前两者与本产品「纯局域网、不出网、内容不离设备」的立场冲突，且验证码/口令这类形态用几条正则就能判个大概——这是检索辅助，不是安全特性，允许漏标和少量误标。

## 决策

1. **本地启发式分类，不是 ML，不是安全特性。** 五类：链接（LINK）、账号（EMAIL）、验证码（OTP）、密码（CREDENTIAL）、文本（PLAIN）。判错的代价只是一次点击，所以规则求简、求可解释，**宁可漏标不误标**（兜底永远是 PLAIN）。
2. **只在渲染时计算，不落库、不迁移、不进同步协议。** 两端历史本就整表进内存（Android 一屏上限 500 条，Windows 全量入 ObservableCollection），筛选在分类后的行上做即可；规则将来演进时旧记录自动跟着新规则走，没有陈旧标签问题。若未来历史量级大到必须让 SQL 分页承担筛选，再补一个**仅本地**的标签列 + 两端各自迁移（该列不进 protocol/v1）。
3. **两端规则逐条镜像。** Kotlin：`android/.../ui/home/ClipContentFormat.kt`；C#：`windows/ClipSync.Core/Clipboard/ClipContentClassifier.cs`。改任何一条启发式必须同步两端实现、两份镜像单测（`ClipContentFormatTest.kt` / `ClipContentClassifierTests.cs`）与本文。
4. **视觉走注记层，不走状态层。** 徽标复用宪章的低彩度着色盒（tokens §4 邻近色，彩度 .03 注记档），固定槽位：账号=青灰(1)、链接=水蓝(2)、验证码=蓝紫(3)、密码=藕紫(4)。**密码不用红**——红只留给真错误；一条口令是待找回的事实，不是警报。PLAIN 不加徽标，安静卡片是缺省。
5. **筛选词汇**（两端一致）：全部 / 链接 / 验证码 / 账号 / 密码 / 文本。Windows 历史页在搜索框下方一排 chip；Android 首页在搜索框下方同一排 chip。选中 = 流动蓝着色盒（与导航选中同一词汇）。

## 分类规则（两端镜像的规范文本）

输入先 trim；空 → PLAIN。判定次序即优先级：**LINK → EMAIL → OTP → CREDENTIAL → PLAIN**。

| 类 | 规则 |
| --- | --- |
| LINK | 单行，整串匹配 `^(https?\|ftp)://\S+$`（忽略大小写）或 `^www\.\S+\.\S+$`。内嵌在正文里的 URL 不算。 |
| EMAIL | 单行，整串匹配 `^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$`（宽松版，不做合法性校验）。 |
| OTP | ① 裸码：整串 4–8 位数字；**例外**：独立 4 位数落在 1900–2099 视为年份 → PLAIN。② 上下文：全文 ≤ 120 字符（短信量级，可多行），含验证码词汇（验证码/校验码/动态码/动态密码/取件码/提取码/认证码/verification code/verify code/security code/one-time/otp/2fa，英文按小写比较），且含独立 4–8 位数字段（两侧非数字）。 |
| CREDENTIAL | 单行，8–64 字符，全部为可见 ASCII（0x21–0x7E，无空白、无 CJK），小写/大写/数字/符号四类中占三类以上；**例外**：含 `/` 或 `\`（路径样）、UUID 形态 → PLAIN。 |
| PLAIN | 其余一切。 |

## 后果

优点：零迁移、零协议变更；规则可解释、可单测、两端可逐条对拍；徽标与筛选立即作用于全部旧记录。

代价：每次刷新都重跑正则（量级几百条 × 几条正则，可忽略）；启发式必然有边界误判（如许可证钥匙被标为「密码」、罕见口令带斜杠被漏标），按「检索辅助」的定位接受；两端规则靠纪律镜像，没有共享代码强制。

## 被否决的方案

- **ML / 云端分类**：与不出网立场冲突，成本与可解释性都不合算；检索辅助不需要那个精度。
- **落库标签列 + 迁移**：眼下没有 SQL 分页筛选的需要；落库会把「规则演进」变成「数据迁移」，还得处理陈旧标签。渲染时算干净得多。
- **把密码类做成安全警示（红色/遮挡）**：用户明确降低安全优先级；且红色在宪章里只属于真错误，把一条历史记录画成警报是对注意力的滥用。
