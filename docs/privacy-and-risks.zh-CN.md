# 剪剪相传 · 使用前必读：隐私与风险说明

[English](privacy-and-risks.md) | **简体中文** | [日本語](privacy-and-risks.ja.md)

这份说明写给使用者。它回答三个问题：你复制的内容会去哪里、谁能看到、哪些事需要你自己留意。每一节先说应用怎么做，再说你能做什么。工程细节见文末链接。

最后更新：2026-09-03。

## 1. 内容去哪里

你在一台设备上复制的文本或图片，只经过你自己的局域网（或 Tailscale 组网）直接送到另一台已配对的设备。连接是加密的，两台设备只认配对时互相记住的证书指纹。中间没有服务器、没有账号；开发者和任何第三方都看不到内容。

两台设备互相连不通时，内容留在本机，重连后补送。

## 2. 已配对设备是完全信任的

配对一旦完成，对方设备就能收到你之后复制的全部文本和图片，直到你暂停、开启私密模式或撤销配对。反过来也一样。

撤销配对、删除单条、清空历史，作用范围都是本机。对方设备上已经收到的副本仍在那里，剪剪相传没有远程删除它们的能力。

你能做的：只配对你自己的设备，或你完全信任的人的设备。设备丢失、送修、转手前先撤销配对（通路 → 设备管理）。

## 3. 到达对端后，剪贴板是共享的

同步到达后，内容默认写进对方设备的系统剪贴板，效果和你在那台设备上手动复制一样。系统剪贴板是共享资源：

- 在电脑上，任何正在运行的程序都能读到剪贴板。
- 在手机上，当前前台应用和输入法能读到剪贴板。
- 网页在你按下粘贴时会拿到内容；部分浏览器还允许网页在你授权后主动读取剪贴板。

也就是说，一段密码从手机同步到电脑后，电脑上任何一个程序都有机会读到它，直到剪贴板被别的内容覆盖。

你能做的：

- 复制敏感内容前，先开私密模式或暂停同步（见第 4 节）。
- 在另一台设备上粘贴完敏感内容后，随手复制一段无关文字覆盖剪贴板。
- 关闭「自动写入」（Windows：偏好 → 同步 → 自动应用远端内容 / 自动应用远端图片；Android：偏好 → 同步 → 自动写入剪贴板 / 自动写入远端图片）。关闭后收到的内容只进历史，你需要时再手动复制。

## 4. 敏感内容也会同步

剪剪相传不判断一段文本是不是密码、银行卡号或验证码。从密码管理器、银行应用复制出来的内容，和别的内容一样进历史、一样同步。应用内有三个工具：

| 工具 | 在哪 | 效果 |
|---|---|---|
| 私密模式 | 双端偏好页；Windows 托盘浮窗也有 | 开启期间复制的内容不进历史、不同步，关闭后也不补发 |
| 暂停 | Windows「暂停捕获」；Android「暂停同步」「暂停自动捕获」 | 停止捕获或停止发送；恢复后按设置补送 |
| 来源过滤 | Windows「屏蔽进程」：填程序名。Android「跳过敏感内容」（默认开）：来源应用把内容标记为敏感时生效，密码管理器通常会打这个标记 | 来自这些来源的复制不记录、不同步 |

## 5. 配对二维码

Windows 出示的二维码里有：本机地址、端口、证书指纹、一条一次性令牌。令牌 5 分钟内有效，用过一次即作废，配对成功后换新。二维码里没有配对密钥。

拿到这个二维码的设备可以向你的电脑发起配对请求。请求到达后，电脑弹出批准窗口，两边屏幕显示证书指纹，需要你在 90 秒内核对并点批准。你不批准，配对就不成立。

你能做的：出示二维码时留意周围，不要让别人拍到；收到不是你发起的配对请求，直接拒绝。

## 6. 局域网上其他设备能看到什么

剪剪相传会在局域网内广播自己的存在（设备 ID、端口、证书指纹），并对任何连上端口的设备回答一条健康状态（协议版本、端口、设备 ID、剪贴板写入是否就绪的状态词）。同一网络里未配对的设备只能知道这些：这里有一台剪剪相传、在哪个端口、设备 ID 和证书指纹是什么。它读不到内容，也写不进内容——进入同步需要配对密钥；发起配对需要二维码里的令牌加你在电脑上的批准，配对请求还有频率限制。

配对页期间，手机会监听电脑的这条局域网信标（只收不发、不回包；信标只含设备 ID、端口、证书指纹），用来确认「电脑就在这个网络上」并把电脑的真实地址排到最前——离开配对页即停止监听。为此 Android 端需要 `CHANGE_WIFI_MULTICAST_STATE` 普通权限（安装时自动授予，不弹窗）；电脑在你打开二维码窗口期间会把广播间隔从 5 分钟缩到 2 秒，关窗即恢复，广播内容不变。

## 7. 防火墙放行意味着什么

手机是主动连电脑的一方，所以电脑需要在 Windows 防火墙放行 TCP 47654 端口的入站连接。首次运行通常会弹出防火墙警报，勾选「专用网络」允许即可。

- 只放行「专用网络」：在你标记为专用的家庭 / 办公 Wi-Fi 上放行；连到公共 Wi-Fi（Windows 默认把新网络归为「公用」）时端口对外关闭，同步也就不通。这是默认取舍。
- 放行「公用网络」：酒店、咖啡馆 Wi-Fi 上同网段的设备也能连到这个端口。它们看到的仍只是第 6 节那点信息，读内容依然需要配对——但暴露面变大了。
- Windows 端应用内（通路页）提供防火墙状态检测与放行 / 移除功能，默认只放行专用网络。放行会在系统里创建一条防火墙规则；卸载前请在应用内移除它，或手动删除。

手动放行与检查方法见[安装指南](install.md)第 3 节。

## 8. Android 特权直读（adb / 无线调试）

Android 10 起，普通应用在后台读不到剪贴板。特权直读是剪剪相传最高一档的后台读取：电脑通过 adb（Android 调试工具）向手机发送一条启动命令，拉起剪剪相传内置的辅助程序，之后手机在后台、甚至息屏时复制的文本也能即时上行。

需要什么：

- 手机打开开发者选项，再打开 USB 调试（数据线）或无线调试（Android 11+，同一 Wi-Fi）。
- 首次连接时，手机弹出「允许 USB 调试？」确认框（无线调试则是扫码或输入配对码），需要你在手机上亲自确认。这一步 Android 不允许任何工具代点。
- 在 Windows 端勾选一次 adb 同意。

它做什么：你点击「启动特权直读」时，电脑运行一次 adb，把启动命令发给手机；其他时候电脑不调用 adb。被拉起的辅助程序只做一件事：读写手机剪贴板的文本。它不联网，不执行别的命令。手机重启后它会关闭，需要你再点一次。

风险：USB 调试和无线调试是 Android 系统级的开发者能力，不只服务于剪剪相传。无线调试打开期间，同一网络里的设备都可以尝试连接手机的调试端口——连上仍需你在手机上确认配对，但这是一个你应当知道的暴露面。

你能做的：不用时关掉无线调试，不要在公共 Wi-Fi 上开着它。不想走这条路，可以选悬浮窗轮询档（不需要电脑），或只用分享面板 / 快捷磁贴 / 通知复制。

## 9. 蓝牙备援

局域网全部不可用时（AP 隔离、VPN 全局接管、路由器故障），已配对的两台设备可以改走蓝牙继续同步。双端默认关闭，需要各自打开，且要先在系统设置里完成蓝牙配对。

- 只传文本。蓝牙期间复制的图片标注「仅本机保留」，之后也不补传。
- 速度远低于 Wi-Fi，一对真机实测约 150–180 KiB/s。
- 蓝牙链路上运行剪剪相传自己的身份校验与加密，沿用配对密钥；系统蓝牙配对只是承载，撤销配对后蓝牙也连不上。
- 剪剪相传不让设备进入「可被发现」模式，只连你选定的已配对设备。但蓝牙是近场无线电，十米左右范围内的设备都能感知到它；蓝牙芯片与系统驱动本身的漏洞靠系统更新修补。

你能做的：不需要时保持关闭；网络恢复后应用自动切回 Wi-Fi。

## 10. 日志与诊断

诊断日志只记录状态码、计数和时间，用来回答「通不通、堵在哪」。剪贴板正文、配对密钥、二维码令牌都在日志之外，有专门的自动化测试守着这一点。托盘菜单「诊断日志」导出的文件可以直接附在问题报告里。

应用崩溃时，崩溃信息留在本机，不上传到任何地方。没有遥测，没有使用统计。

## 11. 导出文件是明文

偏好 → 数据 → 导出历史，会把全部历史写成一个 JSON Lines 文件。文件里不含密钥、证书和配对信息，但每一条剪贴内容都是明文——拿到文件的人能读到全部历史。

你能做的：把导出文件当敏感文件保管；用完即删；不要通过聊天工具或云盘随手转发。

## 12. 隐私默认值一览

| 项目 | 默认 | 你可以 |
|---|---|---|
| 处理什么 | 你复制的文本和图片（PNG / JPEG） | 关闭图片同步 |
| 不采集什么 | 按键、触摸、屏幕、其他应用的界面 | — |
| 图片同步 | 开 | 双端各自关闭 |
| 收到的内容写入剪贴板 | 开（文本与图片各一个开关） | 关闭后只进历史，手动复制 |
| 私密模式 | 关 | 开启后内容不进历史、不同步、不补发 |
| Android 跳过敏感内容 | 开 | 关闭 |
| Windows 屏蔽进程 | 空 | 填程序名 |
| 单条文本上限 | 1 MiB；超过只留本机、不截断 | — |
| 历史保留 | 30 天 / 2 000 条 | 调整；随时清空（只清本机） |
| 蓝牙备援 | 关 | 双端开启 |
| 特权直读 | 关；每次由你在电脑上点击启动 | 撤销 adb 同意 |
| 通知 | 只说「收到内容」，不含正文 | Android 可关闭通知 |
| 日志 | 状态码、计数与时间 | 导出诊断 |
| Android 云备份 | 剪贴历史排除在系统备份与设备迁移之外 | 用导出 / 导入迁移 |
| 遥测 / 崩溃上报 | 没有 | — |
