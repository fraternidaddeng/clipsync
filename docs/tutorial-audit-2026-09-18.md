# 教程与上手路径审查（2026-09-18）

本轮只核对用户会看到的上手文案、安装指南和入口路径，依据当前源码与资源，不依据外部发布页。代码入口证据：Android 首次页为 `MainActivity.kt` 的 `OnboardingScreen`，步骤数据在 `ui/onboarding/OnboardingContent.kt`；Windows 首次页为 `OnboardingWindow.xaml` / `OnboardingWindow.xaml.cs`，步骤数据在 `ClipSync.Core/Onboarding/OnboardingSteps.cs`。

- 三语 README 将“永远可用”“exactly-once”“每条连接都 TLS”这类没有必要的绝对或实现术语改为用户可验证的描述。

## 当前入口对账

| 操作 | Android | Windows |
|---|---|---|
| 首次引导 | 首次未配对安装显示；完成或跳过后可从「偏好 → 帮助 → 重新查看引导」重看 | 首次显示；同样可从「偏好 → 帮助 → 重新查看引导」重看 |
| 配对 | 「通路 → 网络 → 去配对」；首次引导结束的「去配对」直达扫码 | 首次引导配对页直接出二维码；主窗「通路 → 配对新设备」 |
| 后台读取 | 「通路 → 本机读取 → 打开引导」，路线状态以实测 read/write 探针为准 | 「通路 → 特权直读」卡；检测手机、无线配对/连接和启动命令均由用户点击触发 |
| 蓝牙备援 | 「通路 → 网络」卡或「偏好 → 蓝牙备援」 | 「通路 → 网络」连接卡 |
| 隐私说明 | 首次引导与偏好帮助中的外部链接 | 首次引导与偏好帮助中的外部链接 |

## 仍需后续处理的内容

1. 设备矩阵的 `NOT_TESTED` 是质量记录纪律，不适合放在普通用户快速路径里反复强调；README 已改成链接到矩阵并说明含义，后续可以把矩阵状态移入“验证记录”章节。
2. `docs/install.md` 仍是一份面向排障和发布者的长文。普通用户应优先读顶部路径表和第 6、8 节；可以在后续拆出一页“第一次同步”，把防火墙命令、Tailscale、adb 打包说明移入折叠或附录。
3. Windows 其余 15 种语言的 onboarding 长文案仍由资源卫星文件提供旧译文；本轮保证 `zh-Hans`、`zh-Hant`、`en`、`ja` 与实现一致，其余语言键完整但应安排母语复核。`check-i18n-parity.py` 只检查键和占位符，不检查语义新鲜度。
4. UI 仍同时在配对页、通路页和偏好页解释部分相同的蓝牙/权限事实。保留入口本身有价值，但可把长描述收成一条事实行，详情放进安装指南。
