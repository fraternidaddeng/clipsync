四段 · 四种填充同屏可辨
只有一段在伸手四段中最多一段能「伸手」。网络段未配对，所以即使对端写入也未打通，它只显示「未探测」——按管道顺序只点亮上游那段。
顺序即排障顺序读取 → 服务 → 网络 → 写入，是剪贴内容从手机到电脑的实际路径。用户只需看到管子在第几段变细，不需要理解特权直读的 binder 细节。
降级必须一眼可辨52% 半填充与满填充的差异在余光里成立。特权直读通道卡死 bug 正是永久停在降级态——画得和就绪差不多，故障就会静默几个月。
配对挂在网络段下配对的本质就是接通网络段。健康屏的 23 种状况各自挂到对应管道段，不再平铺。5 个页面收成 3 个位置：一屏 / 通路 / 偏好。
这就是「通透」的字面兑现把应用的核心状态做成一条看得见流动的管道，美学词和功能词是同一个词，不是比喻。
