Android · 暖 · 标签只出现在冷色项
修正后的语法是完全镜像的：暖＝手机，冷＝电脑，永远如此，与你正在看哪台设备无关。加上「缺省即本地」，每一端都只给对侧来的项打标签——于是两边的标签颜色天然互补，同一条剪贴项在两台设备上颜色一致。

顺带的收益：标签数量少了约四成，而信息量反而增加了（现在颜色真的编码了来源）。这就是「不杂乱」最典型的实现方式——删掉的是冗余，不是信息。

CHANGELOG改了什么，依据是什么

七处。版面结构、控件位置、信息层级一律未动。
改动前 → 后依据 / 收益
1卡片浮起方式嵌套毛玻璃 → 提高不透明度 WPF 渲染不出嵌套 backdrop blur。改用 .42→.88 的不透明度跃迁 + hover 时才出现的阴影。观感几乎无损，且这是唯一能两端一致的做法。顺带省掉一次昂贵的模糊合成。
2本地项去标签「本地复制」灰标签 → 无标签 缺省即本地。「无标签＝此地」在两端都成立，是完美镜像的语法。删掉近四成标签，静息状态噪音显著下降。
3冷暖轴＝设备轴Android 端的 PC 来源用暖 → 改用冷 本次最实质的修正。原版同一个暖色在两端表示相反的意思。修正后暖恒等于手机、冷恒等于电脑，与观察者所在设备无关。见「对偶检验」页。
4筛选 chip四个常驻 → 移入搜索聚焦态 一屏只有一个主角。四个 chip 与卡片列表争夺同一层视觉权重。它们只在检索意图出现时才有用，藏进聚焦态即可。
5状态点改呼吸静态圆点 → 4s 呼吸 + 文案收短 状态即背景的最小实现。连接活着＝在呼吸，断开＝凝固。「Pixel 8 · 直连中」缩为「Pixel 8」——呼吸本身已经说了「直连中」。
6圆角嵌套定律输入框 12px → 9px；卡片 16px → 11px 内 = 外 − 内边距。外壳 24px、内边距 21px 时，内层理论值 3px 偏小，取一档折中让两条弧接近同心。半透明会把角落几何关系放大，这一处最容易「说不上来哪里怪」。
7Emoji 换线性图标📋🔗⚙️ → 单色 1.8px 描边 这条对双端统一是硬伤。Emoji 在 Windows 走 Segoe UI Emoji、Android 走 Noto Color Emoji，造型和配色完全不同，会直接让两端看起来像两个应用。而且彩色 emoji 无法参与你的低彩度体系——它们是画面里彩度最高的东西。
没有改的：配色本体、字体搭配、三层阴影配方、环境光场、间距节奏、所有文案位置与信息架构。这是一次调音，不是重新编曲。
本页的渐变用了 CSS in oklab，原生端拿不到。移植时必须用技术实验室 §01 生成的预计算色标表替换——WPF 和 Compose 的渐变都只有 sRGB 插值。这是唯一一处「浏览器里好看、原生端要额外干活」的地方。
