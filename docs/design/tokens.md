## 三、色彩 · 状态色（彩度第三档 .09）

全应用常驻色相只有两个：灰蓝（底与流动共用 ~250）、赭黄（召唤 ~65）。红是第三个，只在真正 error 时露面。**绿色（色相 100–180）全区禁用。**

| 令牌 | 日间 | 夜间 | 语义 |
|---|---|---|---|
| `flow` | `#215f8f` | `#6fa8d4` | 流动蓝：就绪 / 流动 / 主操作 |
| `flow-bg` | `rgba(33,95,143,.10)` | `rgba(111,168,212,.13)` | 流动着色底 |
| `flow-ln` | `rgba(33,95,143,.24)` | `rgba(111,168,212,.30)` | 流动描边 |
| `on-flow` | `#f6f9fc` | `#0c1116` | 流动填充上的文字 |
| `act` | `#9b6b24` | `#d9a15c` | 召唤赭：**唯一允许打断你的颜色** |
| `act-bg` | `rgba(155,107,36,.11)` | `rgba(217,161,92,.12)` | 召唤着色底 |
| `act-ln` | `rgba(155,107,36,.28)` | `rgba(217,161,92,.30)` | 召唤描边 |
| `err` | `#a8342b` | `#e0776c` | 红：**仅 error**（写入失败、证书变更）。不用于「不可用」 |
| `err-bg` | `rgba(168,52,43,.09)` | `rgba(224,119,108,.12)` | 错误着色底 |
| `err-ln` | `rgba(168,52,43,.24)` | `rgba(224,119,108,.28)` | 错误描边 |

### 彩度三档 = 三个语义层

```
底色      C ≈ .015   环境
设备色    C ≈ .030   标注
状态色    C ≈ .090   信号
```

眼睛天然把彩度读作重要性，状态永远赢——不需要额外规则保证优先级，物理上就成立。**背景的彩度永远不能超过压在它上面的文字。**

按**配对顺序**分配（第一台 195、第二台 215……），非哈希，允许手动改。落在 195–335 的连续弧上，避开绿（100–180）、红（5–32）、赭（65）。日间值取自 `hue_relation.html`；夜间值为同色相、同彩度、明度抬升的 OKLCH 推导（与流动蓝日夜关系一致），**待实机核验**——纲领已注明藕紫 305 / 灰粉 335 是最可能出问题的两个。

## 五、胶片颗粒（单端技术修补，非设计语言）

| 参数 | 值 |
|---|---|
| 强度 | 日间 **3.0%**（染黑）· 夜间 **4.2%**（染白） |
| 贴图 | **一张** 256×256 纯 alpha 噪声贴图（RGB 全黑，仅 alpha 带噪声），日夜共用，切主题只换染色 |
| 缩放 | **1 纹素 = 1 物理像素，永不缩放** |
| 铺设范围 | **只铺手机应用背景一处**。卡片内部、Windows 托盘浮窗、通知、磁贴一律不铺 |

- Android：贴图放 `res/drawable-nodpi/grain.png`（`nodpi` = 永不缩放），`ShaderBrush(ImageShader(bitmap, TileMode.Repeated))` 平铺，`ColorFilter.tint` 染色。
- Windows：**不用**。它的功能是打碎手机端大面积灰蓝渐变的色带，Windows 端没有这个问题。

## 九、动效

| 令牌 | 值 | 说明 |
|---|---|---|
| `ease` | `cubic-bezier(.16, 1, .3, 1)` | **两端逐位相同**（骨） |
| `dur-win` | 180–220ms | Windows 交互过渡 |
| `dur-droid` | 260–320ms | Android 交互过渡 |
| `dur-theme` | 400–450ms | 日夜切换交叉淡化 |
| `pulse` | 2.6s 无限循环 | 「需要你操作」的描边脉动（外扩 5px 光环渐隐） |
| `flow-run` | 1.8s 线性循环 | 管道流动点（三点相位差 0.6s） |
| 悬停位移 | **1px**（仅向上） | 层次靠阴影从 `sh-1` 跳 `sh-2` 传达，不靠位移幅度 |

**禁用**（时间性 / 不可移植）：22s 环境漂移、镜面流光（仅配对成功可考虑一次）、嵌套毛玻璃、渐进式模糊、色散折射。模糊只能是渐进增强——有则更透，无则提高不透明度，版面一格不动。

## 十、状态编码：一个形，五种填充

同一形态（圆头胶囊段）的填充程度编码五种状态，只花两个色相：

| 状态 | 配方 | 关键判断 |
|---|---|---|
| **需要你操作** | 空 + `act-bg` 底 + 1.5px `act` 描边 + 2.6s 脉动 | **全屏唯一会伸手的** |
| **就绪** | `flow` 满填充 | 好消息不该抢注意力 |
| **降级** | `flow` **52%** 半填充（轨道 `sf3`） | 必须一眼可辨——半满差异要在余光里成立 |
| **不可用** | `sf3` 灰实填充 + `ln2` 描边 | **陈述事实，不是错误**。绝不能长得像错误 |
| **未探测** | 透明 + 1.5px `ln2` 虚线轮廓 | 缺信息 ≠ 坏消息 |

硬规则：

1. 红色只留给 error（写入失败、证书变更），别的一律不用。
2. 四段管道中**最多一段能「伸手」**；若两段同时需操作，按管道顺序只点亮上游那段。
3. rail（四段状态条）在手机状态带、Windows 标题栏、通路页三处**复用同一语汇**。
4. 一屏之内只有一个主角：一个实心主按钮、一处最高彩度、一个 z2 层。

管道四段固定顺序：`本机读取 → 本机服务 → 网络 → 对端写入`。

## 十一、Compose 映射注意事项

1. **Material3 角色映射**（`Theme.kt` 重写基准）：

   | M3 角色 | 日间 | 夜间 | 来源令牌 |

   | `primary` | `#215f8f` | `#6fa8d4` | `flow` |
   | `onPrimary` | `#f6f9fc` | `#0c1116` | `on-flow` |
   | `secondary` | `#6b7a8b` | `#8b98a8` | `t3` |
   | `tertiary` | `#9b6b24` | `#d9a15c` | `act` |
   | `background` | `#e2e9f2` | `#0c1116` | `bg` |
   | `surface` | `#f6f9fc` | `#1b232e` | `sf` |
   | `surfaceVariant` | `#e7edf5` | `#1f2833` | `sf3` |
   | `onSurface` | `#1c2733` | `#e3e9f0` | `t1` |
   | `onSurfaceVariant` | `#6b7a8b` | `#8b98a8` | `t3` |
   | `outline` | `#bcc9d9` | `#3e4a59` | `ln2` |
   | `outlineVariant` | `#cfd9e6` | `#2c3744` | `ln` |
   | `error` | `#a8342b` | `#e0776c` | `err` |

2. M3 角色装不下阶梯与设备色，另建 `ClipSyncColors`（`CompositionLocal`）承载：`sfIn / sfUp / bgGrad / sfGrad / t2 / t4 / flowBg / flowLn / actBg / actLn / errBg / errLn / dev1..dev5`。
3. 渐变用 `Brush.linearGradient`；底渐变 178° ≈ 垂直略斜，可直接 `verticalGradient` 近似。
4. 阴影：z1 = `Modifier.shadow(3.dp)` + 1px 边框；z2 = `Modifier.shadow(12.dp)`；凹陷面用内层渐变叠层模拟内阴影。**夜间靠 `sfUp` 提亮，不加深 elevation。**
5. 颗粒：见第五节。只在最外层 `Box` 的背景绘制，卡片内部不铺。
6. 动画时长用 260–320ms + `CubicBezierEasing(0.16f, 1f, 0.3f, 1f)`。
7. `isSystemInDarkTheme()` 保留；两套 `ClipSyncColors` 与两套 `colorScheme` 同步切换。

## 十二、WPF 映射注意事项

1. `App.xaml` 现为空资源字典——把全部令牌放进 `ResourceDictionary`（`Color` + `SolidColorBrush`，键名 `Cs` 前缀），日夜两个主题字典运行时整体替换。**XAML 页面里不再出现任何十六进制字面量**（迁移清单见 `token-migration-checklist.md`）。
2. 底渐变 / 受光渐变用 `LinearGradientBrush`（178° 用 StartPoint/EndPoint 近似垂直）。
3. 阴影三层拆嵌套 `Border`：`DropShadowEffect` 只挂最外层一次（避免重复光栅化）；中间层 1px `ln` 边框；最内层 2px 高白色渐变作顶部高光。
4. 圆角：窗口 14 / 卡片 10 / 控件 8；`CornerRadius` 遵守嵌套定律。
5. 指纹与时间戳的 `FontFamily` 从 `Consolas` 换成随包分发的 `JetBrains Mono`（`Fonts/#JetBrains Mono`）；中文正文显式指定 `Noto Sans SC`。
6. 托盘浮窗（440px、约 3 秒可见）：不铺颗粒、无任何时间性动效；标题栏右侧放四段 rail。
7. 托盘图标：折线标记单色绘制（替换 `SystemIcons.Application`），「需要你操作」时在折线转折点亮一个赭黄小点——不换图标、不加角标。
