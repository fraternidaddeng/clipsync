# 剪剪相传 · 图标系统

> 从属于《设计纲领》（`DESIGN-CHARTER.md`）与 `tokens.md`。冲突时以纲领为准。
> 资产在 `docs/design/icons/`，全部为手写路径的生产级 SVG。
> 最后更新：2026-08-24

---

## 一、语言规则（所有图标共守）

| 规则 | 值 | 理由 |
|---|---|---|
| 风格 | **单色线性**（monochrome line） | 纲领 5.8：系统表面只给你单色形状的设计权。应用内沿用同一语言，托盘到页签学一次处处认得 |
| 网格 | 导航/动作 **24×24**（Android 24dp / Windows 24px 原生）；托盘 **16×16** 原生绘制 | 托盘 16px 是缩不下去的下限——不缩放 24 网格，直接在 16 网格上重画，端点落在 0.5px 上以对齐物理像素 |
| 线宽 | 24 网格 **1.7**（少数强调动作 1.9）；16 网格 **1.6** | 与预览稿中 `.sgi`（1.7）、`.asr`（1.8）一致 |
| 端点/转角 | `round` / `round` | 与超椭圆几何同族的柔和感 |
| 填充 | **一律 `fill:none`** | 唯一例外：托盘「需要你操作」的赭点（见下） |
| 颜色 | **一律 `currentColor`** | 图标不带色，色来自容器语境 |
| 闭合区域 | 尽量避免 | 齿轮、实心徽章类在 16px 全糊；滑轨、折线、取景框缩得下去 |

### 颜色语境（由容器决定，不写进 SVG）

| 语境 | 颜色令牌 |
|---|---|
| 静默/未选中 | `t4`（Windows 侧栏）或 `t3` |
| 选中/激活 | `flow`（唯一的激活色） |
| 需要你操作 | `act`（仅状态语境，非导航） |
| 不可用 | `t4` + 60% 不透明 |
| **绿色** | **不存在。色相 100–180 全区禁用** |

## 二、托盘图标（Windows，100% 时间可见的表面）

折线标记 `M2 8h3l1.5-3.5 3 7 1.5-3.5h3`（16 网格）是应用唯一的标记：6 个顶点、无闭合区域、单笔画。四个状态**共用同一条线**，变化的是线本身的形态——不换图标、不加角标：

| 状态 | 文件 | 配方 | 语义 |
|---|---|---|---|
| 常态（监听中） | `tray-flow.svg` | 折线本体，单色 | 内容在流动 |
| 需要你操作 | `tray-attention.svg` | 折线 + **峰顶转折点亮一枚赭点**（r 2.4，唯一非单色元素） | 纲领 12.7 原文落地：「不换图标、不加角标」 |
| 已暂停 | `tray-paused.svg` | **同一笔画，振幅归零**——折线放平成直线 | 流动停了，线还在。陈述事实的灰，不是错误 |
| 私密模式 | `tray-private.svg` | 同一条折线改**虚线**（dash 2.4 / gap 2.1） | 轨迹不留档：线在走，痕迹不记 |

实施注意：

- `currentColor` 交给宿主决定：浅色任务栏用 `t1` 日值，深色任务栏用 `t1` 夜值。生成 ICO 时输出 16/20/24/32 四档，**每档按本 SVG 几何重新光栅化**，不要拿 32px 缩到 16px。
- 赭点是托盘上唯一的彩色像素。SVG 内置折中值 `#C08A3E`；若按任务栏主题分套出图，日用 `act` 日值 `#9b6b24`、夜用 `#d9a15c`。
- 私密模式与暂停同时生效时显示**私密**（虚线）——私密是更强的承诺。
- 托盘之外（浮窗页脚、通知）复用同一状态语汇，不另造图标。

## 三、导航 / 区块图标（PC 主窗口左栏 · Android 底栏共用）

三个位置的 IA 两端一致（一屏·历史 / 通路 / 偏好），图标也一致——**骨共享**；渲染尺寸与间距各端自便——**皮各异**。

| 图标 | 文件 | 形 | 用在 |
|---|---|---|---|
| 历史 / 一屏 | `nav-history.svg` | 两页交叠 | PC 左栏 · Android 底栏 |
| 通路 / 同步状态 | `nav-conduit.svg` | 折线标记本体（24 网格 `M4 12h4l2-5 4 10 2-5h4`） | PC 左栏 · Android 底栏 · 品牌=状态，一形两用 |
| 偏好 / 设置 | `nav-prefs.svg` | 三条滑轨带旋钮 | PC 左栏 · Android 底栏（替换早期三横线——三横线与「列表」歧义） |
| 设备 | `nav-devices.svg` | 显示器 + 手机并立 | 通路·网络段的设备区块头 |

## 六、尺寸档

| 场景 | 尺寸 | 来源网格 |
|---|---|---|
| Windows 托盘 | 16 / 20 / 24 / 32 px（ICO 多档） | 16 网格 |
| Windows 左栏导航 | 17–19 px 显示（24 网格缩放） | 24 网格 |
| Android 底栏 | 24dp | 24 网格 → VectorDrawable 直译 |
| 着色盒内来源字形 | 10–12 px | 24 网格；线宽 1.8 保证缩小后仍可辨 |
| Android 通知 / QS 磁贴 | 24dp 单色 | `nav-conduit.svg` 折线标记（系统表面只认单色形状） |

落地方式：Windows 端转 `DrawingImage`/`Geometry` 资源（键名 `CsIcon*`），不要嵌 PNG；Android 端逐条路径转写为 `VectorDrawable`（`android:tint` 接 `currentColor` 语境）。两端不得改动路径几何——这是「骨」。
