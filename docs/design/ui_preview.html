10 个开关 · 按语义分 5 组
这一页是真正的排版考题10 个开关、每个挂 1–3 行说明，总共约 400 字。任何装饰在这里都是负担——通透只能靠分组、行距和字号层级实现。这就是为什么颗粒不铺卡片内部。
五组标题用等宽小字9.5px、字距 .14em、大写、灰四级。它们要能被跳过——扫视时视线应该直接落在开关名上，组标题只在需要定位时才被读到。
说明文字不能省「原始字节含 EXIF」「这不代表剪贴板权限」——这些是隐私承诺，删掉就是欺骗。设计要适应诚实的文案，不是反过来。
「暂停同步」建议提级它是使用频率最高的开关，而且通知栏和 QS 磁贴上都需要它。留在这里是妥协——更好的位置是状态带上一个可点的暂停态。
非开关项用「值 ›」保留天数、额外包名数，右侧显示当前值而不是开关。一眼能读到当前配置，不用点进去确认。
清除历史不给红色它是常规操作且有二次确认。红色留给真正的 error。破坏性操作靠确认对话框防护，不靠颜色恐吓。

证书变更 · 全应用最高风险时刻
证书变更是唯一该用赭黄整块背景的地方这是全应用最高风险的决策点——误确认等于接受一个可能的中间人。所以这里破例：整块底色 + 实心警示按钮。其余任何地方都不该这么响。
指纹用等宽 + 四位分组 + 两行64 个十六进制字符要和 Windows 屏幕上的逐字比对。等宽保证字符宽度一致，四位一组便于用手指跟读，两行避免横向扫视丢位。这是 mono 最正当的用途。
主按钮文案保留「我已核实」不是「确认」。按钮文案本身就是一次责任确认——用户点下去时读到的是自己做过的动作。
配对不是独立页面它挂在「通路」的网络段下——配对的本质就是接通网络段。dock 上高亮的是「通路」，不是第四个 tab。
二维码静区留足四角定位框用流动蓝，暗示「这里是入口」。静区（白边）必须足够，否则灰蓝底会干扰识别。

这三个表面你几乎没有设计权通知与磁贴由系统绘制：字体、圆角、背景、强调色全部来自系统主题，MIUI 还会二次改写。你能控制的只有：单色图标的形状、文案、以及动作按钮的数量与顺序。
所以折线标记必须在 24dp 单色下成立它同时是应用图标、通知图标、磁贴图标、托盘图标和「通路」页的 dock 图标。选它的理由：6 个顶点、无闭合区域、单笔画——缩到 16px 仍可辨，且深浅任务栏都成立。
动作按钮的顺序是设计后台通知给了三个：全部暂停 / 立即同步 / 打开状态。「全部暂停」放第一位——它是最高频且最需要即时可达的操作，用户掏出通知栏多半是为了它。
文案里的隐私承诺不能删「从不包含剪贴板文本」「这不代表剪贴板权限」——常驻通知是用户唯一能持续看到的地方，这两句在这里的价值高于任何视觉设计。
入站通知只有一个动作「复制到剪贴板」。不加「忽略」——划掉就是忽略，系统已经提供了这个手势。多一个按钮就是多一次决策。
