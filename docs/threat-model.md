# ClipSync 威胁模型

状态：阶段 0 基线；Stage 9 图片扩展补充于 2026-08-20。

## 保护目标

- 剪贴板正文、图片 blob、历史、来源和删除状态。
- 设备身份、TLS 私钥、证书指纹、一次性配对令牌和 pair secret。
- 事件完整性、来源序号、游标、outbox、ack 与 tombstone。
- 用户对暂停、私密模式、设备撤销和 Android 特权能力的控制权。

## 信任边界

1. Windows/Android 本地进程与本地数据库。
2. Windows DPAPI、Android Keystore 和 Shizuku UserService 等高权限边界。
3. 两个 peer 之间的不可信网络。
4. Android 系统剪贴板、OEM 实现、logcat 和 overlay 窗口。
5. 构建依赖、侧载安装包与更新介质。

局域网、VPN 和配对前的远端设备均不可信。已配对 peer 可读取同步给它的正文，因此设备丢失或被攻陷后必须撤销。

## 主要威胁与控制

| 威胁 | 影响 | 阶段性控制 |
|---|---|---|
| 局域网窃听或中间人 | 正文、身份泄露或篡改 | TLS 1.3、证书 SHA-256 指纹固定、双方明确确认 |
| 未配对设备调用接口 | 注入或读取内容 | 未配对设备只能读取有限健康状态；挑战响应和 pair secret 鉴权 |
| 配对二维码/令牌重放 | 非预期设备获得信任 | 一次性令牌、成功后失效并重生成、双方显示名称和指纹 |
| 伪造设备 ID、旧令牌或旧连接 | 绕过撤销 | secret 与设备绑定、本地 trust epoch、撤销后删除 secret 并关闭连接 |
| 重复、乱序、丢包 | 重复显示、缺失或游标越洞 | `origin_device_id + origin_seq` 幂等键、连续游标、`received_ranges`、持久化后 ack |
| 远端写回触发回环 | 无限同步、历史污染 | `originEventId` 与内容哈希抑制；所有 backend 共用去重逻辑 |
| 崩溃或断网导致数据丢失 | 未发送内容消失 | 先本地事务落库，再进入 per-peer outbox；内存队列不作为可靠状态 |
| 恶意/异常输入耗尽资源 | 内存、磁盘或解析器 DoS | 1 MiB 文本上限；图片 16 MiB / 32 MP / 8192 px；分块 256 KiB；JSON 深度、帧大小、连接速率和批量限制 |
| 解码炸弹或超大图片 | 内存耗尽、崩溃 | 先读头再有界解码；拒绝坏魔数、截断和超限输入；超限 `local_only` 或 `drop`，不截断 |
| 路径穿越或任意 URI 当正文 | 读取用户文件或外部内容 | 捕获后立即物化到应用私有 content-addressed 文件；不把 URI/路径写入事件正文或同步层 |
| 图片正文进入日志/崩溃信息 | 持久化泄露 | 日志只含状态、计数、尺寸统计和稳定错误码；禁止正文、原图、缩略图字节和 URI |
| 剪贴板正文进入日志/崩溃信息 | 持久化泄露 | 日志只含状态、计数和稳定错误码；禁止正文、原始 logcat 行和命令输出 |
| 本地密钥明文保存 | 本机用户或恶意软件窃取 | Windows DPAPI、Android Keystore；密钥不进入配置、日志或 Shizuku 服务 |
| Shizuku API 过宽 | shell 身份被滥用 | UserService 仅暴露剪贴板读/写、listener 注册/注销和 health；不通过 Binder 传整张 Bitmap，不接网络包、不执行任意 shell |
| `READ_LOGS` 过度采集 | 其他应用敏感信息泄露 | 只在内存识别复制信号，不保存/上传原始行；权限需显式授予与撤销 |
| overlay 截获输入 | 触摸或键盘劫持 | 1x1、透明、始终 `FLAG_NOT_TOUCHABLE`；只短暂获取焦点，失败即标为不支持 |
| 敏感应用内容被同步 | 密码或金融信息泄露 | 来源黑名单、用户自定义规则、私密模式、一键暂停；不猜测密码内容 |
| 依赖或分发包被篡改 | 任意代码执行 | 锁定依赖、CI、许可证/漏洞审查、签名 APK、发布包 SHA-256（后续阶段） |

## 隐私默认值

- 文本第一版只处理纯文本。图片同步必须由用户显式开启，默认关闭。
- MVP 保留通过校验的原始 PNG/JPEG 字节（含元数据）；后续隐私模式再评估去 EXIF。
- 不采集触摸、键盘、屏幕或其他应用 UI。
- 私密模式下内容不写历史、不进入 outbox，退出后不补发。
- 被策略拒绝的事件只记录原因码。
- 本地清空不承诺删除其他设备已接收的副本，UI 必须明确说明。
- 不提供默认遥测和云端崩溃上报。
- 图片历史列表只加载 512 px 缩略图；通知和诊断不附带图片正文。

## 剩余风险

- 已配对但已被攻陷的设备可读取此前同步给它的内容；撤销不能远程擦除旧副本。
- Android OEM 对剪贴板、锁屏、后台运行和 overlay 的实现不同，可能导致降级或短暂焦点影响。
- TLS 保护传输中数据，但第一版不对已落地数据库启用强制 SQLCipher，也不提供经过 Relay 的应用层 E2EE。
- 来源应用识别可能不可用；未知来源不得被误判为可信。
- 已配对设备可读取同步给它的图片原字节和元数据；图片自动同步关闭时仍可能在本机历史中留下本地捕获。

## 不作为安全方案的做法

不能通过降低 `targetSdk`、Root、静默 adb、默认开启 overlay、无障碍监听、隐藏权限提示或记录正文来换取功能可用。第三方项目只作为行为研究依据，不能替代官方约束、许可证检查和实体机验证。
